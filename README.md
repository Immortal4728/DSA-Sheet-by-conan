# 🚀 SDE-1 DSA Roadmap — Pattern-Based Learning

> **Goal:** Don't memorize solutions. Learn to **think**, recognize patterns, and solve unfamiliar problems on your own under interview time pressure.

This repository is a **pattern-first, SDE-1-focused DSA roadmap** designed to build genuine problem-solving intuition rather than solution dependency.

📖 **Must-Read Before You Begin:** Check out [How to Learn DSA (Without Tutorial Hell)](./HOW-TO-STUDY-DSA.md), [How to Recognize Patterns & Think Through DSA Problems](./HOW-TO-RECOGNIZE-PATTERNS.md), and [Optimization, Complexity & Fast Approach Selection](./HOW-TO-OPTIMIZE-AND-SELECT-APPROACHES.md) for the memory-first mental model, self-solving framework, and optimization ladder.

🎯 **When You Are Ready to Interview:** Use the [Interview Execution System](./interview-execution/README.md) — the structured mental framework for deploying everything you've learned under live interview pressure.

The curriculum is structured around:
- **Pattern recognition** over memorization
- **Problem-solving under interview time constraints**
- **Transfer to unfamiliar problems**
- **Progressive difficulty**
- **Strong fundamentals before advanced topics**
- **Blank-editor implementation**
- **Understanding why a pattern works** rather than memorizing code
- **Interview-oriented problem selection**
- **Avoiding unnecessary problem-count inflation**
- **Avoiding competitive-programming-only material**

## 💡 Curriculum Philosophy

### 1. Pattern First
Problems are organized around reusable problem-solving patterns rather than arbitrary topic lists.

### 2. Canonical Ownership
Every problem has one canonical home in the repository. If a problem connects to another topic, it is referenced as a bridge/cross-reference, but never physically duplicated.

### 3. Depth Over Volume
Different patterns receive different numbers of questions based on their actual SDE-1 interview value. The curriculum does not inflate question counts merely to reach arbitrary numbers.

### 4. Transfer Over Memorization
Later problems increasingly require the learner to identify the underlying pattern independently without solution hints.

### 5. Interview Focus
The syllabus prioritizes practical SDE-1 interview problem-solving over competitive-programming-only techniques or obscure algorithmic tricks.

## 📚 Section-Level Roadmap

### 01 — Arrays + Searching + Sorting
Build the foundation for array manipulation, searching, sorting, and core array problem-solving patterns.

### 02 — Strings
Apply array-style reasoning to strings while developing string-specific traversal, hashing, window, matching, and transformation techniques.

### 03 — Hashing & HashMaps
Learn fast membership, frequency, complement, prefix-state, and composite-key lookup techniques.

### 04 — Linked Lists
Master pointer manipulation, reversal, fast/slow pointers, merging, partitioning, and linked-structure reasoning.

### 05 — Stacks & Queues
Develop stack, queue, deque, monotonic structure, expression, and simulation patterns.

### 06 — Binary Trees
Build general tree traversal, recursive state, path, view, construction, transformation, and tree-DP reasoning.

### 07 — Binary Search Trees
Add ordering invariants, search pruning, predecessor/successor reasoning, modification, construction, and range queries.

### 08 — Heaps & Priority Queues
Master top-K, selection, dynamic ordering, K-way merge, scheduling, greedy-with-heap, and priority-based reasoning.

### 09 — Recursion & Backtracking
Develop recursive state modeling, decision-tree exploration, pruning, generation, constraint solving, and hidden backtracking recognition.

### 10 — Dynamic Programming
Learn how to identify state, transitions, overlapping subproblems, optimal substructure, and progressively harder DP formulations.

### 11 — Graphs
Develop graph modeling, traversal, connectivity, shortest paths, topological reasoning, and graph-specific problem-solving patterns.

### 12 — Binary Search / Search on Answer
Extend binary search beyond sorted arrays into boundaries, rotated structures, monotonic predicates, and answer-space optimization.

### 13 — Greedy Algorithms
Learn to identify locally optimal decisions that produce globally valid solutions, including scheduling, intervals, and optimization patterns.

### 14 — Tries
Learn prefix-based data structures and efficient string/set queries where trie structure provides a meaningful advantage.

### 15 — Bit Manipulation
Build practical understanding of binary representation, bitwise operations, masks, XOR patterns, and interview-relevant bit techniques.

### Interview Execution
The structured system for deploying all DSA knowledge under live interview conditions: clarification, constraint analysis, brute force → optimization, pattern recognition, explanation, and timed practice modes.

## 🎯 SDE-1 Focus

This repository is specifically designed for:
- SDE-1 technical interviews
- Product-company technical interviews
- Strong coding rounds
- Pattern recognition speed
- Problem-solving under time pressure
- Blank-editor implementation

It intentionally avoids:
- Random filler problems
- Repetitive variants with little additional learning value
- Competitive-programming-only techniques
- Obscure advanced algorithms without SDE-1 relevance
- Artificially equal question counts across patterns

## 🛠️ How to Use This Repository

```text
1. Learn the concept.
2. Study the pattern structure in the corresponding topic folder.
3. Solve representative problems from a blank editor.
4. Identify the pattern before coding.
5. Explain the approach clearly.
6. Analyze time and space complexity.
7. Revisit mistakes.
8. Solve hidden/unfamiliar variations.
9. Move forward only when the pattern is transferable.
```

> **The goal is not to memorize solutions. The goal is to recognize and reproduce the underlying reasoning.**
