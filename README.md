You become good by learning to recognize the problem,
finding the bottleneck, and building the solution yourself.

You start by learning the language of problems.

Then you learn the patterns.

Then the patterns begin to overlap.

Eventually, the labels disappear.

A problem arrives.
No topic is given.
No pattern is named.

You read it.
Think.
Find the bottleneck.
Recognize the structure.
Choose the technique.
Optimize.
Code.
Explain.

That's the skill this roadmap is building.
